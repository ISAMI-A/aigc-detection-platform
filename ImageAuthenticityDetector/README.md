# ImageAuthenticityDetector - TruFor 图片篡改检测工具（V2.4）

基于 **TruFor（CVPR 2023）** 的图片篡改检测工具。支持两种模式：

- **通用单图检测**：任意目录/单张图片，不需要配对命名，自动识别
- **配对对比检测**：`数字.png`（原图）+ `数字p.jpg`（P图）成对对比

输出带缩略图、热力图、分析图的 Excel 报告。

---

## 技术方案详解（简历/汇报素材）

### 1. 系统定位

基于 **TruFor（CVPR 2023）** 的 AIGC/PS 篡改检测工具：输入一张图片，输出
「是否篡改 + 像素级篡改定位 + 可解释分析依据」的 Excel 报告。核心价值在于把
学术界只输出热力图的 TruFor 模型，工程化为**可直接落地的多指标融合判定系统**，
经 6 个业务版本迭代（V1 → V2.4）准确率从 71.7% 提升至 86.8%。

### 2. 底层模型：TruFor 篡改检测框架

TruFor 的核心思想是**多模态融合取证**——篡改区域即使视觉上无瑕疵，其**噪声指纹**
也会因重新编码而与周边不一致：

```
输入图片 ──┬─→ RGB 流 → SegFormer(mit_b2) 编码器 ──┐
           │                                        ├─→ CMX 跨模态融合解码器 ─→ 输出
           └─→ Noiseprint++ 流（DnCNN 噪声残差提取）─┘         ├─ 篡改定位图 loc_map（像素级篡改概率）
                                                            ├─ 置信度图 conf_map（噪声分析置信度）
                                                            └─ 全局篡改分数 score
```

- **Noiseprint++**：提取相机/生成器的噪声残差指纹（PRNU 思想的深度学习版），
  对拼接、复制移动、AI 生成等"视觉无痕"篡改敏感；
- **SegFormer（mit_b2）**：轻量层级式 Transformer 编码器（NeurIPS 2021），提取语义特征；
- **CMX 融合**：RGB 语义流与噪声流的跨模态特征融合 + MLP 解码器，输出像素级定位；
- 本项目使用官方预训练权重（`trufor.pth.tar` / `noiseprint++.th` / `mit_b2.pth`），
  **未做重训练**——创新点全部在判定层（见下）。

### 3. 判定层：多指标融合判定引擎（本项目核心创新）

官方 TruFor 只给 heatmap，无法直接回答"这张图是否篡改"。本项目在模型输出之上
构建了 **13 个统计指标 + 两轮检验 + 疑似仲裁 + 三类降级** 的完整判定体系：

#### 3.1 loc_stats 统计指标（从 loc_map/conf_map 提取 13 维特征）

| 类别 | 指标 | 含义 |
|---|---|---|
| 峰值/范围 | peak、loc75 | 篡改概率峰值、≥0.75 高概率区占比 |
| 面积 | area、conf_area | 篡改区占比、高置信区占比 |
| 连通域 | n_comp、max_comp、max_rect、max_solid | 成片区域数、最大成片占比、最大矩形度、最大紧致度 |
| 深红 | deep_ratio | loc≥0.80 深红区占比（最强证据） |
| 边缘 | touch_ratio、edge_band_ratio | 篡改区贴边占比、边缘带占比（边缘误检特征） |
| 散点 | spots | 零散小区域数（噪声误检特征） |

#### 3.2 两轮检验规则

1. **一轮初判**：篡改概率 score ≥ THRESHOLD（0.5）→ 进入二轮；否则通过；
2. **二轮画笔标注降级**：部分用户会在图片上**画红色矩形框标注问题区域**，TruFor 会把
   涂抹痕迹误判为篡改。两种情况降级放行：
   - 常规线状标注：矩形度/紧致度/细长度几何特征命中（框是规则细线）
   - 深红线状标注：深红区 loc≥0.75 无 conf 置信伴随（涂抹的深红是"实心框"特征）
3. **二轮边缘误检降级**：贴边占比 + 边缘带占比双高 → 篡改区贴着图像边缘出现，
   典型为模型边缘误检，降级放行；
4. **疑似仲裁**（消灭中间态）：深红区占比超过 deep_threshold 时升判为"篡改"，
   低于则降为"通过"——业务上不允许输出"疑似"让用户自己猜；
5. **散点噪声降级**：最大成片占比极小且散点数多 → 概率噪声，放行。

#### 3.3 几何特征分析（V2 新增，模块 `geometry_analyzer.py`）

对深红高概率区做连通域分析，计算**矩形度/紧致度/细长度/圆度**四类形状因子，
用于区分"真实篡改（不规则形状）"与"人画标注框（规则细线）"。技术细节：
采用 `cv2.minAreaRect` 最小外接矩形，并做了 **+0.5 像素中心化修正**——
minAreaRect 返回的角点坐标是外推到整数像素的，对一两个像素宽的细线区域
会系统性高估宽高，修正后才可稳定用于细线检测。

#### 3.4 阈值校准（模块 `calibrate.py`）

判定体系含 5 个阈值（thr/peak/area/comp_ratio/spots），采用**网格搜索 +
K 折分层交叉验证**自动校准：网格 9×3×5×4×3 = 1620 组组合 × 5 折，
以 F1 为主指标、Precision/Recall 为约束，防止过拟合单批数据。

### 4. 预处理流水线（模块 `image_preprocess.py`）

统一把异构输入规整为 TruFor 兼容格式，杜绝脏输入导致的模型崩溃：

| 步骤 | 处理 | 目的 |
|---|---|---|
| 损坏检测 | 强制解码校验 | 提前拦截损坏/伪装后缀文件 |
| 色彩空间 | CMYK → RGB | TruFor 只接受 RGB |
| 透明通道 | RGBA → 白底合成 | PNG 透明区不含噪声信息，白底化统一口径 |
| 超大图 | LANCZOS 等比缩放 ≤2048 | 控制显存；LANCZOS 抗混叠保高频噪声细节 |
| 统一编码 | 转 JPEG quality=95 | 统一压缩痕迹口径（q95 视觉无损） |

### 5. 子进程推理架构（模块 `forgery_detector.py`）

- TruFor 以**子进程**方式运行，与判定主程序隔离——模型崩溃不拖垮主流程；
- `predict_batch` 批量模式：**模型只加载一次**跑完整个目录（单图逐张加载要数十秒/张，
  批量摊薄后约 1~2 秒/张）；
- **进度实时转发**：`os.read` 逐块非阻塞读取子进程 stdout，解析 tqdm 进度条
  实时回传，批量检测不再是黑盒；
- 健壮性：子进程强制 UTF-8 编码；TruFor 原版 `os.path.join` 遇 "\" 开头的绝对路径
  会重置到盘符根导致 npz 散落 D:\ ——已做路径兼容修复。

### 6. EXIF 元数据分析（模块 `exif_analyzer.py`）

辅助证据维度：检测 EXIF 中的编辑软件痕迹（Photoshop/GIMP/Stable Diffusion/
Midjourney 等关键词）与异常缺失，作为深度模型判定之外的旁证。

### 7. 报告工程

Excel 报告三图并排（缩略图/篡改热力图/几何分析图）+ 判定列红绿着色 + 13 项
量化指标列；输出 Excel 被占用时自动改名重试，不因文件锁中断批任务。

### 8. 版本演进（详见后文"版本历史"）

V1 基础阈值判定（71.7%）→ V2 画笔标注降级 + 几何分析 → V2.2 边缘/散点降级 →
V2.3 疑似仲裁消灭中间态 → V2.4 参数校准（86.8%）。

## 使用方法

### 通用单图检测（推荐）

```powershell
# 单张图片
python run.py -dir "任意图片.jpg"

# 目录批量（递归子目录）
python run.py -dir "图片目录" -o output_trufor
```

### 配对对比检测

目录中如果存在 `数字.png` + `数字p.jpg` 成对文件，自动进入配对模式：

```powershell
python run.py -dir "test_images/testss"
```

### 参数配置

`run.py` 顶部配置区可调整（当前为 testss 校准值）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `THRESHOLD` | 0.35 | 篡改概率 >= 该值 → "是" |
| `FUSE_PEAK` | 0.70 | 疑似判定：热力图峰值阈值 |
| `FUSE_AREA` | 0.05 | 疑似判定：热力图区域占比阈值 |
| `COMP_RATIO` | 0.005 | 散点噪声过滤：最大成片占比下限 |
| `COMP_N_SPOTS` | 16 | 散点数量下限 |
| `GEOM_RECT` | 0.25 | 画笔标注降级a：最大连通域矩形度阈值 |
| `GEOM_SOLID` | 0.30 | 画笔标注降级a：最大连通域紧致度阈值 |
| `GEOM_MIN_AREA` | 200 | 画笔标注降级：线状连通域面积下限（px） |
| `GEOM_LOC_THR` | 0.75 | 画笔标注降级b：深红线状检测 loc 阈值（无 conf） |
| `GEOM_LINE_RATIO` | 0.50 | 画笔标注降级b：深红区"线状面积占比"阈值 |
| `SUSPECT_LOC_THR` | 0.75 | 疑似仲裁：深红区 loc 阈值（无 conf） |
| `SUSPECT_UP_THR` | 0.01 | 疑似仲裁：深红区占比分界（>=升判"是"，<判"否（深红区过小）"） |
| `EDGE_BAND` | 0.10 | 边缘误检：边缘带宽度（图像宽高的比例） |
| `EDGE_TOUCH_RATIO` | 0.90 | 边缘误检：贴边连通域面积占比阈值（红色直接触及边界，无蓝色间隔） |
| `EDGE_BAND_RATIO` | 0.50 | 边缘误检：边缘带内红色占比阈值（排除覆盖中心的大面积篡改） |
| `MAX_SAMPLES` | 0 | 随机抽样数量（0=全量） |

命令行参数 `--threshold` / `--peak` / `--area` 等可覆盖配置区值。

## 判定规则（V2.4 两轮检验 + 疑似仲裁 + 边缘误检降级）

```
一轮：篡改概率 >= THRESHOLD → "是（有篡改痕迹）"
  二轮（画笔标注复核，命中则降级"否（画笔标注）"）：
    a) 常规线状：mask=loc>=0.5 & conf>=0.5 最大连通域
       矩形度 < GEOM_RECT 且 紧致度 < GEOM_SOLID 且 面积 >= GEOM_MIN_AREA
    b) 深红线状：mask=loc>=GEOM_LOC_THR（无 conf 限制）
       深红区"线状连通域面积占比" >= GEOM_LINE_RATIO
  二轮（边缘误检复核，命中则降级"否（边缘误检）"，V2.4）：
    贴边面积占比 >= EDGE_TOUCH_RATIO（红色主体 bbox 直接触及图像边界、与边缘间无蓝色间隔）
    且 边缘带红色占比 >= EDGE_BAND_RATIO（红色集中在四周 EDGE_BAND 边缘带内）
    → 模型边缘误检（如 testss 2/13 原图右边缘整条竖带）
否则 峰值 >= FUSE_PEAK 且 面积 >= FUSE_AREA → 疑似候选（仲裁，无"疑似"中间态）：
    └─ 最大成片 < COMP_RATIO 且 散点数 >= COMP_N_SPOTS → 降级"否（散点噪声）"
    └─ 深红区占比（loc>=SUSPECT_LOC_THR 无conf）>= SUSPECT_UP_THR
       → 升判"是（有篡改痕迹）"（V2.2，真篡改深红区明显）
    └─ 深红区占比 < SUSPECT_UP_THR（增强图红色区域很小/很少）
       → 降级"否（深红区过小）"（V2.3，模型未检测出显著篡改）
否则 → "否"
```

### 为什么需要二轮（V2 画笔标注检测）

测试数据中存在**人工红色画笔圈/涂鸦标注**（不应算作篡改），TruFor 会把画圈当篡改信号输出在热力图中：

- **a) 常规线状**：画笔线在热力图（loc≥0.5 且 conf≥0.5）上呈细长弧线，矩形度低、非实心
- **b) 深红线状**：部分画圈线模型的置信度 conf 偏低（<0.5），会被 conf 条件滤掉；
  改用高 loc 阈值（≥0.75，无 conf）单独提取深红区，统计线状面积占比识别

### 疑似仲裁（V2.2 升判 + V2.3 降否）

部分篡改图篡改概率未达阈值，但热力图有成片红色区域（peak/area 达标），进入疑似候选。
此时不看概率、只看**深红区（loc>=0.75，无 conf）占全图比例**，一刀切二分：

- 真篡改的深红区占比高：testss 升判图 1.3%~10.3%（11p/16p/17p/26p 等，V2.2 修复漏判）
- 原图误报/未检出的深红区占比 <1%（3o/4o/6o/6p 等）
- 阈值 0.01 → 占比达标升判"是"；不达标判"否（深红区过小）"，**不再输出含糊的"疑似"**

> 注意：该判定与 conf 无关。曾尝试带 conf≥0.5 统计，会把真篡改的深红区滤掉（指标失真），
> 故深红区一律用无 conf 的 loc 阈值提取。增强图（Excel H/I 列）渲染的就是这份深红区，
> 与判定数值一一对应——肉眼看增强图红色很小 = 深红区占比不达标 = 判否。

### 边缘误检降级（V2.4）

部分**原图**会被模型误检判"是"（如 2/13 原图），特征：红色区域**完全贴边**——直接触及图像
边界，热力图上边缘直接就是红色、与边缘之间没有任何蓝色间隔（右边缘整条竖带/竖条）。

双条件同时满足才降级，缺一不可（避免误伤真篡改）：
- **贴边面积占比 ≥ 0.9**：红色主体的连通域 bbox 直接触及图像边界（= 无蓝色间隔）。
  反例：2p 真篡改的红色虽靠边缘但与边界间有蓝色间隔，贴边占比≈0，天然排除
- **边缘带红色占比 ≥ 0.5**：红色像素集中在四周 10% 边缘带内。
  反例：1p/10p 真篡改的贴边块巨大但覆盖画面中心，边缘带占比低，被排除

testss 校准：22 张判"是"中仅 2/13 命中，其余 20 张（含 1p/2p/10p/12p/19p 等）零误伤。

Excel 的"判定来源"列会标明每条判定来自一轮还是二轮（如 `一轮:概率达标`、`二轮:常规线状`、
`二轮:深红线状`、`二轮:深红升判`、`一轮:深红区过小`、`二轮:边缘误检`）。

**Q: 支持哪些格式？**
A: JPG、JPEG、PNG、BMP、WebP、TIF、TIFF。

**Q: 检测结果是否 100% 准确？**
A: 不保证。建议作为辅助参考，重要场景需人工复核。画笔标注检测参数基于 testss 校准，泛化到新数据需重新验证。
